# Universo da Diversão 🎡🍿

Projeto desenvolvido com HTML, CSS3 e JavaScript puro, criado com o objetivo de apresentar eventos, brinquedos e guloseimas de forma visual, divertida e responsiva.

O Universo da Diversão foi um dos meus primeiros projetos front-end e marcou uma etapa importante da minha evolução como desenvolvedor, sendo o projeto onde comecei a aplicar na prática conceitos de estruturação visual, estilização e interatividade utilizando tecnologias web fundamentais.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## 🎯 Objetivo do projeto

O projeto foi desenvolvido para criar uma experiência visual leve, moderna e divertida, simulando uma página voltada para entretenimento e eventos.

A proposta era apresentar:
- Eventos
- Brinquedos
- Área infantil
- Guloseimas
- Informações visuais de maneira intuitiva

---

## 📱 Funcionalidades

- Interface moderna e responsiva
- Navegação simples e intuitiva
- Sessões organizadas por categorias
- Estrutura visual temática
- Efeitos visuais utilizando CSS3
- Interações básicas com JavaScript

---

## 🧠 Aprendizados durante o projeto

Durante o desenvolvimento deste projeto, foram trabalhados conceitos importantes como:

- Estruturação semântica com HTML5
- Estilização e responsividade com CSS3
- Manipulação básica com JavaScript
- Organização visual de conteúdo
- Criação de layouts modernos
- Primeiros conceitos de experiência do usuário (UI/UX)
